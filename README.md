# 天空鳳凰木 · Sky Poinciana Island

以 React + TypeScript + Vite + Tailwind CSS + Three.js + MediaPipe Tasks Vision 建立的程序化 3D 生態島互動網站。

## 啟動

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

開啟終端機顯示的 localhost 網址。建置正式版：

```bash
npm run build
npm run preview
```

單元測試：

```bash
npm test
```

## 操作

- 滑鼠拖曳/觸控：Three.js 場景目前採固定觀景視角；可用滑鼠滾輪縮放（如需軌道控制，可再加 OrbitControls）。
- 底部控制列：拖曳時間、切換晝夜循環、靜音、細雨與五階段物候。
- 快捷鍵：`H` 收合控制列、`Space` 晝夜循環、`M` 靜音、`1–5` 切換物候。
- 開啟鏡頭後：張手授粉、握拳落果、揮手旋轉風車、YA 手勢換季、食指調時間。
- 無鏡頭測試：控制列中的五個測試按鈕可直接觸發對應互動。

## 程序化資產

場景幾何、植被分布、花朵、豆莢、村落、岩層、瀑布、雲、雨線、星點與合成音效均由程式建立，不依賴外部模型或貼圖。MediaPipe 的 WASM 與手部模型會在啟用鏡頭時從 CDN 載入。

## 部署

`npm run build` 會產生 `dist/`。可部署至 Netlify、Vercel、GitHub Pages 或任何靜態網站主機。手勢辨識需要 HTTPS（localhost 除外）與使用者授權攝影機。

## 實作範圍說明

這是一個可執行的互動原型：具備低多邊形浮島、鳳凰木植被、村落、雙瀑布、風車、瞭望塔、衛星蜜蜂、日夜光照、五階段物候、雲雨、豆莢落地與手勢操作。程序化音效需使用者先取消靜音以符合瀏覽器音訊播放政策。現階段以簡化的程序化合成音色呈現鳥鳴與風聲；豆莢物理為簡化重力與落地震顫。更精細的花粉粒子、落葉、螢火蟲動態、真實連續曲線樹幹、完整物理碰撞及完整 24 小時天空大氣散射仍可在此基礎上擴充。
